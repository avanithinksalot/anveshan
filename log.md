### Module 5 — XGBoost + SMOTE (supervised risk scoring)

**Status:** ✅ BUILT + TESTED (real data, 48,925 works)

Built `src/xgboost_model.py`. XGBClassifier (200 trees, depth 6, lr 0.05) in an `imblearn` pipeline with **SMOTE** up-sampling the minority class to 50/50. 80/20 stratified split, metrics on held-out 20%.
